## 实现

- 两张128×128确定性灰度程序纹理，共享用于地面/沙地的颜色、粗糙度和微小凹凸；米制UV保证纹理密度一致。不改地形顶点高度、碰撞或路段位置。各向异性按硬件能力限制至4。机器人资源包不分配地表纹理。
- 路牌按实际长宽比生成画布，文字测量后适配；避免文字横向拉伸，不改变路标位置和内容。
- 仅14组静态仓库立面做局部实例批处理：462个静态网格绘制项变为182个（含84个实例批次），结构性减少280项/60.6%。保留材质、局部变换、阴影、图层和局部包围体；动态与交互对象不参与。实例资源在换图和退出时释放，不重复释放共享资产。
- 主光、轮廓光与阴影覆盖区域随机器人横向位置移动；退出旁路返回组装时同步复位。
- 地图、底盘、电机、速度、能量、评分、货物、统一交互、路线选择与UI布局保持原规则。
