# 四足动力学

## 使用

选择四足底盘并开始驾驶；物理调试需开启 ?test=1。线上版本见 deploy/DEPLOYED.md。
本地开发可运行 `npm.cmd run dev -- --host 127.0.0.1`，打开 `/preview.html?test=1`。
展开“物理测试”可轻推、强推、扶正、显示受力。橙色标记表示重心及其地面投影；青色箭头表示足部接触力，打滑时变红。扶正保留任务、货物和进度，清除姿态/速度与倒地状态；重新挑战则重建整个会话。

## 实现

- `src/domain/simulation/quadruped.ts`：三维车身刚体状态（位置、四元数、线速度与角速度），固定最大 1/240 秒子步积分。重力、足部力及碰撞力合成平动力和转矩，包含局部惯量与陀螺项。行驶参数提供速度/加速度目标，不直接覆盖物理位置。
- 模块及基础结构按质量加权计算重心；各模块的有限尺寸近似惯量加平行轴项形成对角惯量。装卸货物实时更新质量、重心与惯量，并保持车身几何位置连续。
- 平衡控制根据目标姿态、速度和支撑位置产生期望合力/力矩；投影迭代将其分配到可触地、可达的支撑脚。法向力非负，单腿力有上限，切向力位于库仑摩擦锥内；控制器不能凭空施加直接回正力矩。
- 支撑脚固定在地面，达到摩擦极限时允许滑动；抬起或超出腿长的脚不能提供支撑。重心投影与支撑多边形用于稳定性诊断。车身俯仰、侧倾和横向位移反馈到 IK 与落脚动画。
- 倾斜超过控制范围后停用主动支撑；模块近似包围盒、货箱与折叠脚掌的采样点采用单向弹簧/阻尼碰撞和切向摩擦，产生落地、滑动和耗散。碰撞没有人为固定的翻倒轨迹。
- 持续大角度倾斜并发生碰撞后记录倒地。测试模式仍继续物理计算，允许扶正；正常模式在倒地运动趋稳后判定失败。暂停冻结物理，恢复不补算暂停期间的时间。
- 轮式和履带保持既有运动逻辑；本次三维车身动力学用于四足底盘。

## 模型边界

这是用于当前平地/缓坡场景的简化游戏动力学。腿部采用无质量执行器与两段 IK；车身使用对角惯量近似，碰撞是多个近似形状的点采样软接触。尚不包含各腿独立刚体/关节电机动力学、精确网格碰撞、自碰撞、可变形履带或测量标定的机器人参数。极端冲击仍可能出现少量软接触穿透，不能作为工程级机器人仿真使用。

## 验证

- `node scripts/verify-quadruped.mjs`：重心/惯量、装卸连续性、自由落体、摩擦/力限、静态平衡、扰动恢复、翻倒碰撞、60/120Hz 等价、54套四足配置、平地/缓坡前进制动倒车、暂停/恢复、正常失败/测试扶正、实际渲染适配器固定腿长与倒地足端检查。
- `node scripts/verify-locomotion.mjs`：履带闭环和基础步态/IK。
