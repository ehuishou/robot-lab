## 🚨 高优先级问题

### 1. 油门和刹车按钮失灵

**问题描述：**
- 油门和刹车按钮有时会失灵，无法响应玩家输入
- 可能是虚拟按钮的触摸事件处理不稳定

**复现步骤：**
1. 进入任务执行场景
2. 使用虚拟按钮（触摸或鼠标点击）
3. 某些情况下按钮不响应或响应延迟

**可能原因：**
- `pointerout` 事件过早触发，导致状态被重置
- 多次快速点击可能导致状态混乱
- 虚拟按钮的 `setScrollFactor(0)` 与触摸区域不匹配
- 按钮事件与键盘事件可能存在冲突

**影响范围：**
- 严重影响游戏可玩性
- 移动端尤其明显

**建议修复方案：**
1. 改用按压式触摸检测（检查指针是否在按钮范围内）
2. 添加触摸事件调试日志
3. 考虑使用 `pointercancel` 事件处理异常情况
4. 增加按钮触摸区域的容错范围

**文件位置：**
- `src/scenes/MissionPlayScene.ts:223-265` (createButton 方法)
- `src/scenes/MissionPlayScene.ts:267-292` (setupKeyboardInput 方法)

### 2. 部分装备未发挥作用

**问题描述：**
- 游戏中的 15 个模块，部分在实际游戏中没有明显体现
- 玩家无法感受到某些装备的差异

**具体未生效的装备功能：**

#### 2.1 传感器模块（感知能力）
- **问题**：感知参数（perception）只在约束检查中使用，游戏中没有实际体现
- **当前状态**：设置了 perception 值（摄像头40，深度摄像头70，LiDAR 95）
- **缺失功能**：
  - 应该影响道具的检测范围
  - 应该影响碰撞预警
  - 应该在障碍物环境中有体现
- **文件位置**：
  - `src/data/modules.ts:107-149` (传感器定义)
  - `src/scenes/MissionPlayScene.ts:455-468` (道具碰撞检测 - 固定距离40px)

#### 2.2 稳定性参数（stability）
- **问题**：稳定性目前只在配置界面显示，游戏中无实际作用
- **当前状态**：不同底盘有不同稳定性（轮式50，履带80，四足90）
- **缺失功能**：
  - 应该影响碰撞概率
  - 应该影响在不平地形的表现
  - 应该影响高速行驶的控制性
- **文件位置**：
  - `src/systems/RobotConfig.ts:52-76` (只用于计算，未实际应用)

#### 2.3 负载能力（payload）
- **问题**：负载参数完全未使用
- **当前状态**：只在约束检查中验证最小值
- **缺失功能**：
  - 应该影响机器人质量
  - 应该影响加速性能
  - 应该决定能否搬运某些道具
- **文件位置**：
  - `src/data/modules.ts:151-197` (工具模块定义了 payload)
  - 游戏中完全未引用

#### 2.4 工具模块差异化不足
- **问题**：三种工具（机械臂、推土铲、抓取器）功能差异不明显
- **当前状态**：只有"有工具"和"无工具"的区别
- **缺失功能**：
  - 机械臂：应该能搬运重物道具
  - 推土铲：应该能清除障碍物
  - 抓取器：应该能精确抓取小道具
- **文件位置**：
  - `src/scenes/MissionPlayScene.ts:470-492` (collectItem 方法 - 只检查是否有工具)

#### 2.5 电机效率参数未生效
- **问题**：定义了电机效率（低功耗0.9，标准0.7，高性能0.5），但未在能耗计算中使用
- **当前状态**：三种电机只有扭矩和速度差异
- **文件位置**：
  - `src/data/modules.ts:46-82` (电机定义)
  - `src/scenes/MissionPlayScene.ts:424-435` (能耗计算 - 未使用效率参数)

## 🎨 美术资源问题

### 3. 美术过于粗糙

**问题描述：**
- 当前使用的是简单的几何图形和 Emoji 图标
- 缺乏专业的游戏美术资源
- 视觉效果不够吸引人

**具体问题：**

#### 3.1 机器人表现
- **当前状态**：矩形 + 🤖 Emoji
- **问题**：
  - 无法体现不同底盘的视觉差异（轮式/履带/四足看起来一样）
  - 没有运动动画
  - 没有装备可视化
- **文件位置**：`src/scenes/MissionPlayScene.ts:186-204`

#### 3.2 场景道具
- **当前状态**：圆形 + Emoji（⚡🔋⭐💎）
- **问题**：
  - 辨识度不高
  - 缺乏吸引力
  - 没有动画效果
- **文件位置**：`src/scenes/MissionPlayScene.ts:221-245`

#### 3.3 地形和背景
- **当前状态**：简单的矩形地面，三角形山脉
- **问题**：
  - 无法体现不同地形类型（平地/坡道/崎岖）
  - 背景单调
  - 缺乏层次感
- **文件位置**：`src/scenes/MissionPlayScene.ts:147-163`

#### 3.4 UI 界面
- **当前状态**：基本的文本和矩形
- **问题**：
  - 缺乏游戏感
  - 虚拟按钮不够美观
  - HUD 信息展示单调
- **文件位置**：
  - `src/scenes/MissionPlayScene.ts:165-219` (HUD)
  - `src/scenes/MissionPlayScene.ts:294-323` (虚拟按钮)

**需要的美术资源：**
1. **机器人精灵图**：
   - 3种底盘的差异化造型（轮式/履带/四足）
   - 装备可视化（电机、电池、传感器、工具）
   - 运动帧动画（至少4帧）
   - 大小：约 100x80 像素

2. **场景道具精灵图**：
   - 能源包、得分星星、特殊宝箱
   - 障碍物（石头、木箱等）
   - 带闪烁/旋转动画
   - 大小：约 40x40 像素

3. **地形 Tileset**：
   - 平地瓦片
   - 坡道瓦片
   - 崎岖地形瓦片
   - 背景层（天空、远山、云彩）
   - 瓦片大小：40x40 像素

4. **UI 元素**：
   - 按钮（正常、按下、禁用状态）
   - 能源条边框和填充
   - 图标（能源、速度、时间、得分）
   - 对话框背景

5. **粒子效果**：
   - 尾焰（加速时）
   - 灰尘（移动时）
   - 火花（碰撞时）
   - 星星（收集道具时）

**美术风格建议：**
- 像素艺术风格（8-bit 或 16-bit）
- 或卡通科幻风格
- 色彩以绿色/蓝色科技感为主
- 保持机器人主题的一致性

## ⚙️ 其他技术问题

### 4. 物理模拟简化过度

**问题描述：**
- 当前的物理模拟过于简单，缺乏真实感

**具体问题：**

- 没有悬挂弹簧系统
- 地形交互单一
- 碰撞检测未实现

**文件位置：**
- `src/scenes/MissionPlayScene.ts:371-411` (updateDrivingPhysics)

---

### 5. 任务目标单一

**问题描述：**
- 所有任务都是"到达终点"
- 缺乏多样化的任务目标

**缺失的任务类型：**
- 搬运任务（搬运N个物体）
- 清除任务（清除N个障碍）
- 收集任务（收集N个道具）
- 时间挑战（限时到达）
- 组合任务（多个目标）

**文件位置：**
- `src/data/missions.ts` (任务定义)
- `src/scenes/MissionPlayScene.ts:437-454` (任务状态检查)

---

### 6. 缺少音效和音乐

**问题描述：**
- 完全没有音效系统
- 游戏体验缺乏听觉反馈

**需要的音效：**
- 引擎声音（随速度变化）
- 加速音效
- 刹车音效
- 道具收集音效
- 碰撞音效
- UI 点击音效
- 背景音乐

---

### 7. 缺少教程和提示系统

**问题描述：**
- 新玩家不知道如何操作
- 没有引导玩家理解装备差异

**缺失内容：**
- 新手教程关卡
- 操作提示
- 装备说明弹窗
- 失败后的具体建议
