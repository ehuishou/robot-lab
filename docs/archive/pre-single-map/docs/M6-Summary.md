# M6 完成总结 - 美术资源框架

## ✅ 已完成内容

### 1. 资源清单系统 (`src/data/assetManifest.ts`)

**定义了完整的资源清单**：
- **机器人模块**：3 种底盘、3 种工具、3 种电机、3 种电池、3 种传感器
- **道具和障碍物**：能源包、星星、宝箱、货物、精密零件、石头、木箱、残骸、卸货区
- **粒子纹理**：圆点、火花、烟雾（代码生成）

**每个资源包含**：
- `key` - 资源标识符
- `path` - 文件路径
- `width/height` - 尺寸
- `frames` - 动画帧数
- `priority` - 优先级（P0/P1/P2）
- `placeholder` - 占位图定义（类型、颜色、描边）

**占位图类型**：
- `rect` - 矩形（车身、电池、货箱）
- `circle` - 圆形（车轮、传感器、能源包）
- `polygon` - 多边形（推土铲、星星、石头）

### 2. PreloadScene (`src/scenes/PreloadScene.ts`)

**功能**：
- ✅ 显示科技风加载界面（标题、进度条、加载文本）
- ✅ 自动加载所有资源
- ✅ **占位图自动生成** - 若资源文件不存在，自动生成几何占位图
- ✅ 粒子纹理生成（圆点、五角星）
- ✅ 加载进度显示
- ✅ 加载错误处理

**占位图特点**：
- 使用 `Graphics.generateTexture()` 生成
- 颜色与资源类型对应（青色=机器人、品红=工具、绿色=能源等）
- 半透明 + 描边，科技风格
- 包含资源 key 标签（白底黑字），方便识别
- 支持精灵表（多帧动画）

## 🔄 美术文件替换流程

**开发不被美术进度阻塞**！

### 当前状态
游戏使用占位图运行，所有功能正常。

### 替换步骤
1. 美术提供 PNG 文件（透明背景）
2. 放入 `public/assets/sprites/` 目录
3. 命名与 `assetManifest.ts` 中的 `path` 一致（如 `chassis_wheel.png`）
4. **刷新游戏 - 自动替换占位图**

### 优先级建议
- **P0（高优先级）**：底盘、工具、能源包、星星、轻货、精密零件、障碍物 - 核心玩法
- **P1（中优先级）**：电机、电池、传感器、宝箱 - 增强视觉
- **P2（低优先级）**：残骸 - 可选内容

## 🎯 美术规范

### 通用要求
- 格式：PNG，透明背景
- 朝向：机器人朝右
- 锚点：底部中心（机器人、地面物体）/ 中心（其他）
- 风格：科技风 / 像素风，主色青色 (#00ffff) + 品红 (#ff00ff) + 绿色 (#00ff00)

### 动画精灵表
- 横向排列，每帧同尺寸，无间距
- 示例：`chassis_track.png`（128×64 × 4 帧 = 512×64）

### 尺寸参考
- 底盘：128×64 / 128×80
- 工具：40-64 像素
- 道具：40-50 像素
- 模块：24-44 像素
