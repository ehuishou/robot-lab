## 🔍 详细测试场景

### 场景 1: 任务 01 - 基础功能
**目标**: 验证基础玩法 + 多目标系统

1. 进入"任务 01 - 平地运输"
2. 使用默认配置开始
3. **观察右上角目标列表**:
   ```
   目标:
   □ 运送轻货 0/1
   □ 到达终点
   
   可选:
   ☆ 限时 30s
   ```
4. 拾取轻货（📦）→ 观察目标更新为 "1/1"
5. 到达绿色卸货区 → 自动卸货
6. 到达终点 → 任务成功
7. **预期**: 两个主要目标都变为 ▣，可选目标显示剩余时间

**验证点**:
- ✅ 按钮响应稳定
- ✅ 道具拾取和卸货正常
- ✅ 目标列表实时更新
- ✅ 任务成功条件正确

---

### 场景 2: 任务 02 - 工具和障碍物
**目标**: 验证传感器、工具能力、障碍物

**配置**: 轮式 + 标准电机 + 标准电池 + LiDAR + 推土铲

1. 进入"任务 02 - 山地运输"
2. 观察目标:
   ```
   目标:
   □ 运送轻货 0/2
   □ 到达终点
   
   可选:
   ☆ 碰撞限制 0/1
   ```
3. 前进时观察：
   - 远处的障碍物先显示为半透明（未识别）
   - 靠近后变清晰（LiDAR 识别距离远）
4. 撞击木箱（📦）:
   - 推土铲：清除木箱，显示"清除!"
   - 不计入碰撞
5. 撞击石头（🪨）:
   - 任何工具都会碰撞
   - 目标更新为"碰撞限制 1/1"
   - 可选目标可能失败（如果设置了上限）
6. 拾取 2 个轻货并卸载
7. 到达终点

**验证点**:
- ✅ LiDAR 显形距离明显更远
- ✅ 推土铲能清除木箱
- ✅ 碰撞计数正确
- ✅ 运送目标正确追踪

---

### 场景 3: 任务 03 - 精密搬运
**目标**: 验证抓取器的独特能力

**配置 A** - 无工具:
1. 进入任务，靠近精密零件（⚙️）
2. **预期**: 无法搬运，显示"需要精密抓取工具"

**配置 B** - 机械臂:
1. 重新配置，装备机械臂
2. 靠近精密零件
3. **预期**: 显示"机械臂会损坏精密零件"

**配置 C** - 抓取器:
1. 重新配置，装备抓取器
2. 观察目标:
   ```
   目标:
   □ 运送零件 0/3
   
   可选:
   ☆ 打开宝箱
   ```
3. 成功搬运 3 个零件到卸货区
4. 靠近宝箱（💎）:
   - 抓取器：打开宝箱，额外奖励
   - 可选目标完成
5. 任务成功

**验证点**:
- ✅ 不同工具对精密零件的反应不同
- ✅ 抓取器独有能力
- ✅ 可选目标不影响任务成败

---

### 场景 4: 物理模拟体验
**URL**: http://localhost:3001/?physics=true  
**任务 02** - 山地运输

**对比测试**:

1. **轮式底盘**:
   - 通过崎岖地形
   - **预期**: 弹跳明显，颠簸感强

2. **履带底盘**:
   - 通过相同地形
   - **预期**: 平稳贴地，几乎不弹跳

3. **地形观察**:
   - 地面有平缓的起伏
   - 上坡时车身后仰
   - 下坡时车身前倾
   - **重要**: 坡度应该平缓，不会太陡

**验证点**:
- ✅ 地形有起伏但平缓
- ✅ 车身角度随地形变化
- ✅ 不同底盘手感有差异
- ✅ 不会轻易翻车

## 🐛 已知问题检查

### 问题 1: 目标列表不显示
**症状**: 右上角没有目标列表  
**原因**: 任务可能没有 `objectives` 字段  
**解决**: 只有任务 01-03 添加了多目标，任务 04-05 仍使用旧系统

### 问题 2: 物理模拟无效果
**症状**: 地面仍是平的  
**原因**: 未启用 `?physics=true` 参数  
**解决**: 确保 URL 为 `http://localhost:3001/?physics=true`

### 问题 3: 按钮仍然失灵
**症状**: 机器人移动后按钮无响应  
**原因**: M1 的修复可能有遗漏  
**报告**: 提供复现步骤
